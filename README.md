# Simulador do RPM

Página interativa: https://mthsleal.github.io/simulador-rpm/

Antecipa a Tabela 2.2.1 do próximo Relatório de Política Monetária do Banco Central (projeções de IPCA,
IPCA Livres e IPCA Administrados, acumuladas em 4 trimestres) a partir da última publicada, revisando as
premissas: Selic, expectativas de inflação, câmbio, Brent, crescimento do PIB (que vira o hiato) e a
inflação corrente. Os efeitos vêm de uma réplica do modelo semiestrutural desagregado do BCB, calibrada
contra as respostas a impulso publicadas no RI de junho de 2024.

Um único arquivo (`index.html`), gerado por `bcb/simulador-rpm` no repositório de trabalho; não edite à mão.
